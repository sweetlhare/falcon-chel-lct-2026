# Метод

## Вход и признаки

Модель получает RGB-изображение и BBox `[x, y, width, height]` в пикселях.
Время, камера, местоположение и истинный vehicle ID не являются входами инференса.
Обнаруженные номерные области расширяются и закрываются серым значением 127.
При неудаче детектора используется геометрическая fallback-маска. Этот механизм
не гарантирует полного удаления номерных признаков.

Замороженный DINOv3 ViT-B/16 обрабатывает crop 256×256. Глобальный признак
получается average pooling, не CLS. Плотная сетка признаков усредняется 16×16→8×8.
Обученные локальные ветви оценивают полезность областей на межкамерных парах;
это обученное предпочтение, не гарантированная инвариантность к ракурсу.
PCA, обученная на train, сжимает их до 64 и 192 координат.

## Глобальная метрика

KISSME использует ковариации разностей для одинаковых и разных ID; положительно
полуопределённая часть разности обратных ковариаций задаёт преобразование.
Ridge 0.1 выбран на calibration. Обучение глобальной головы использовало
2500 изображений 400 train ID и все пары по идентичности, без фильтра камеры.
Не смешивать это с межкамерным обучением локальных ветвей.

Три нормированных блока имеют размерности 768,64,192. При объединении используются
веса 0.75,0.1875,0.0625 (масштаб блоков — квадратный корень веса), затем итоговая
нормировка. Сравнение — чистое скалярное произведение единичных векторов,
без pairwise reranking. Вклад каждого блока точно восстанавливает итоговый score.

## Порог и галерея

Порог выбран на V2 calibration по pair-F1 в точных точках изменения top-10
cosine, затем зафиксирован: **0.3633712828159332**. Граница применяется
как `score >= threshold`; равные оценки принимаются вместе.

API разделяет полный диагностический `ranking` и принятые `candidates`.
`refused` истинно, когда принятых нет. UI показывает до десяти снимков для
ручного разбора; ниже-пороговый снимок не считается найденным совпадением.
Галерея хранит fingerprint модели, поэтому векторы разных моделей нельзя
незаметно смешать. Поиск точный по всей небольшой галерее, ANN пока нет.

## Что не реализовано

Детекция автомобилей, OCR и трекинг не входят в задачу. Семантические названия
частей, VLM-объяснения, восстановление маршрута и миллионная галерея не заявляются.
Использованные методы известны; сила композиции оценивается измерениями,
а не названием или числом компонентов.
