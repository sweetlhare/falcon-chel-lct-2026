# HTTP API

Локальная точка входа Compose: `http://127.0.0.1:8799`.
Интерактивный контракт — `/docs`, точная схема — `/openapi.json`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | Модель, размерность, число объектов и порог |
| POST | `/encode` | Вектор и карта весов локальных признаков |
| POST | `/search` | Поиск по галерее и token текущего поиска |
| POST | `/explain` | Полный пересчёт вмешательств для выбранного кандидата |
| POST | `/gallery` | Добавление/обновление объекта; только доверенный доступ |
| GET | `/examples` | Доступные примеры из подготовленной конкурсной поставки |
| GET | `/search-example/{image_id}` | Поиск подготовленного примера |
| GET | `/explain-example/{image_id}` | Объяснение примера с `search_token` |
| GET | `/preview/{image_id}` | Подготовленное изображение для просмотра |

## Собственное изображение

`image_base64` — обычный base64 содержимого JPEG/PNG, без префикса data URL.
`bbox` — `[x,y,width,height]` в пикселях исходного изображения, не `x1,y1,x2,y2`.
`top_n` от1до20; UI использует10. BBox проверяется относительно размеров кадра.

```python
import base64, json, urllib.request
payload = {
    'image_base64': base64.b64encode(open('car.jpg', 'rb').read()).decode(),
    'bbox': [20, 30, 400, 250],
    'top_n': 10,
}
request = urllib.request.Request(
    'http://127.0.0.1:8799/search',
    data=json.dumps(payload).encode(),
    headers={'Content-Type': 'application/json'},
)
result = json.load(urllib.request.urlopen(request, timeout=60))
print(result['refused'], result['candidates'])
```

Пример предполагает, что файл и BBox существуют и галерея уже наполнена.
`ranking` содержит диагностический список, `candidates` — только прошедших
порог; `refused` не означает доказанное отсутствие автомобиля.
`score` — cosine, `contributions` — три вклада. `search_token` и `provenance`
нужны для привязки объяснения.

Для `/explain` отправьте тот же payload, добавив `search_token` из результата
и `target_id` из его ranking. Галерея должна содержать минимум два объекта.
Не переиспользуйте token для другого изображения или изменённой галереи.
Объяснение существенно дороже одного поиска: оно повторно кодирует варианты.

Для доверенного `/gallery` добавьте к payload строковое `image_id`
(буквы, цифры, `_`, `.`, `-`, до128символов). Публичный демонстрационный шлюз
должен блокировать эту операцию; база не должна изменяться случайными посетителями.

## Ошибки

- `422`: невалидное изображение/BBox/параметры или невозможность объяснения.
- `409`: token устарел, вход/модель/галерея изменились или кандидат не из поиска.
- `503`: галерея недоступна; повторить после восстановления DB.

При409 повторите поиск и используйте новый token. Не подменяйте hashes вручную.
Лимит поля base64 —24миллиона символов, изображения —30MP. Внешний reverse proxy
может вводить более строгие ограничения и возвращать413/429/503.
