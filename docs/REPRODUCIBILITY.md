# Воспроизводимость и контракт артефактов

Публичная версия содержит исходники. Изображения, строки dataset/split,
готовые веса и конкурсные результаты предоставляются отдельно правообладателем
или организаторами. Их отсутствие в Git явно ограничивает воспроизведение:
свежий clone позволяет проверить код/синтетические тесты, но не повторить
заявленные метрики или запустить модель без дополнительных файлов.

## Модель

Нужен каталог `weights/`:

| Файл | Назначение |
|---|---|
| `manifest.json` | Имена компонентов, их SHA256, backbone, threshold и параметры |
| `backbone.safetensors` | DINOv3 ViT-B/16 |
| `chel_v1.npz` | Первая локальная ветвь и центрирование |
| `chel_v2.npz` | Вторая локальная ветвь |
| `compression.npz` | Обученные преобразования сжатия |
| `global_metric.npz` | KISSME-преобразование global768 |
| `plate_redaction.onnx` | Детектор номерных областей |

Размер выбранных весов366526289байт. Fingerprint manifest выбранного решения:
`baafd6b9cb4a431152dd6db6054ef571d313a8ee1b8310352aedc41f2ade409f`.
Хэш устанавливает соответствие конкретному эксперименту, но не заменяет
сам файл и право использования. Условия DINOv3 сохранены в `licenses/`.

## Инференс

После получения весов и разрешённого архива организатора:

```bash
python inference.py --archive data/dataset.zip --weights weights --output outputs/new_run
python validate_outputs.py --archive data/dataset.zip --output outputs/new_run
```

`new_run` не должен существовать. Для этих команд нужны зависимости модели;
для автономного выполнения используйте подготовленный Docker-образ.
Выпуск содержит submission.csv, candidates.csv, embeddings.npy и служебные
rows/pooling/redactions/report/model_manifest для проверки происхождения.
Порядок query/gallery определяется метаданными организатора, не именами файлов.

## Обучение

В публичном коде сохранены encoder, обучение локальных ветвей, сжатие,
метрическая голова и evaluation. Команды: [TRAINING.md](TRAINING.md).
Приватный исследовательский протокол
использовал2500trainизображений400ID и отдельную calibration. Seeds:
20260924 для локальных ветвей,20260925 для сжатия,20260928 для новых контролей.

Для точного повтора требуются **исходные фиксированные** metadata/split/masks
и encoder cache с manifests. Новое случайное разбиение не воспроизводит те же
цифры. Не объявляйте исследованные V2/V4–V7 новым независимым holdout.
На своих данных сначала зафиксируйте train/calibration/evaluation по ID
и общим кадрам, затем обучайте PCA/метрики только на train и порог на calibration.

Отдельный скрипт `train_global_metric.py` воспроизводит уже выбранную голову:

```bash
python train_global_metric.py --self-test
python train_global_metric.py \
  --training-features replay/training_features \
  --training-rows training/training_cpu_rows.jsonl \
  --center-weights weights/chel_v1.npz \
  --output replay/global_metric
```

Имена путей здесь — контракт для ваших явно подготовленных входов, не файлы,
которые уже лежат в публичном Git. Скрипт проверяет связывание ID/векторов,
размерность, конечность, train-only центр и отказ от перезаписи.
Все команды требуют реальных подготовленных артефактов. Полного приватного
training/split набора в публичном checkout нет.

## Что действительно проверено

- Глобальная голова пересчитана по сохранённым train-признакам: center/transform
  совпали побитово в проверенном offline-окружении.
- Свежий encode восьми изображений отличается от исследовательского пути
  не более2.468e-6 по вектору.
- Полный цикл encoder→обучение всех ветвей→выходы заново не повторялся.
- Выходной валидатор проверен на целых и намеренно повреждённых данных.
- Результаты и hashes не публикуются как доказательство скрытого теста.

Разница BLAS/CPU может изменить FP32 и NPZ-байты. Сравнивайте массивы,
векторы, решения и provenance; имя каталога не является доказательством версии.
Полнота визуальных масок требует отдельного человеческого аудита: корректный
JSON/BBox и инвариантность внутри маски не доказывают, что все номера закрыты.
